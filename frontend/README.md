# LOCUS AI Frontend

Sign-up landing page matching the Figma design (Flow 6 — intro pages).

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Project structure

- `src/pages/SignUpPage.tsx` — Sign up with Google landing page
- `src/components/` — Header, logo, stepper, dashboard preview
- `public/dashboard-preview.png` — Dashboard mockup cropped from Figma screenshot for pixel-accurate right panel
